Reporting a problem?

  1. Describe what you were doing, what you expected, and what happened.
  2. Include the app version and build from the Help (?) button at the top left of Journal.
  3. Include your iPhone model and iOS version from Settings → General → About.
  4. If useful, attach a screenshot with personal details removed.

You do not need to send your whole journal. Share only the details needed to explain the issue. See how support messages are handled.

A few quick answers

Start here.

How do I record my first workout?

Create a folder with the toolbar’s +, add an exercise using the folder’s +, then tap + beside the exercise. Enter the set and tap OK. The getting-started guide walks through it.

Does it work without an internet connection?

Yes. Core journal use is local and works offline.

Does my journal sync between devices?

No. Lift & Hop does not provide live journal synchronization. You can export a CSV and import it on another device. Review Add versus Replace before importing.

I left Manage workout. Were my changes saved?

Only if you tapped Save at the top. Cancel or dismissing the screen discards unsaved changes. OK inside its set editor updates the draft; it does not save the entire workout. See editing workouts.

How do I recover from an import?

Open Import → Recovery backups, select the earlier journal and choose Replace journal. Local recovery files are saved before each import. Export the current journal first if you want to preserve it too.

Why is my CSV rejected?

The app accepts CSV files in the Lift & Hop format. A general spreadsheet CSV may need conversion. Keep the original file, note the validation message and contact support if needed.

How do I make a separate backup?

Use Journal → ••• → Export → Share CSV → Save to Files. Choose an off-device destination such as iCloud Drive and verify the saved file there. A recovery copy on the same phone is not a separate backup.
